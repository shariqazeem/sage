quickqueue

A tiny job queue for Node, backed by SQLite. No Redis, no broker, one file.

Quickstart

Install it with npm install quickqueue, then run node examples/hello.js to see a job picked up and finished.

Retries

A job that throws is retried three times with a growing delay, then moved to the failed list.
