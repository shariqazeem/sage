# The 3-minute demo — Sage on Arc

Read the SAY lines. Do the DO lines while you say them. Camera only for the first and last beat.
One browser window at 1440 wide, signed out at https://sagepays.xyz. A second private window for the
worker. Clipboard: a one-line gig (below). Testnet USDC in the account before you start (the script
`arc-treasury.mjs` + `fund.ts`, or the faucet).

```
Publish a public page containing the text SAGE-ARC-2026 and submit its URL. $1, one slot.
```

## 1 · 0:00 → 0:12 · CAMERA
SAY › I'm Shariq. Sage is an AI agent that pays people for verified work. It has paid forty-one people
on GOAT mainnet and thirteen on Starknet. This month we brought it to Arc, Circle's chain — on testnet

## 2 · 0:12 → 0:40 · the account
DO › Sign in with email (or wallet). Open **Account**, then the **Arc** tab (marked new · testnet).
SAY › This is the whole setup. One wallet on Arc, held under a mandate the agent can't widen. Send USDC
to it from any wallet or exchange. Or bridge it in from Ethereum or Base — Circle's App Kit, CCTP
underneath, Circle mints straight into the account. On Arc, USDC is the gas, so this is all it ever
needs. No second token, no top-ups.
DO › Rest on the QR, the bridge form, the balance.

## 3 · 0:40 → 1:20 · the agent launches
DO › **Post work** → paste the gig → create. On the plan page choose **Launch from the account**
(or run `arc-launch.mjs` off camera and cut to the campaign page).
SAY › I don't touch a key. The agent creates the vault on Arc, approves, funds and activates it — four
signatures inside the mandate. Here's the campaign, live on Arc, one dollar, one slot.

## 4 · 1:20 → 2:10 · a worker gets paid
DO › Second window: the campaign page → connect the worker wallet → submit the gist URL.
SAY › A worker submits. Sage fetches the page, checks the marker, the judge decides, and the vault pays.

## 5 · 2:10 → 2:40 · withdraw, and the ledger
DO › Back to **Account**. Withdraw 0.50 to any address → confirm → the transaction link.
SAY › And out: any address, one permit for exactly this amount, then the account locks back to the
mandate. Every move is on the explorer, and every payout has a public receipt.
